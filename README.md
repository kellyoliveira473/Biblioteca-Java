# 📚 Biblioteca Java

Projeto desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos (POO) e organização de código utilizando diferentes camadas e responsabilidades.

## 🎯 Objetivo

O projeto simula uma aplicação de gerenciamento de uma biblioteca, permitindo praticar a criação e organização de classes, modelos, contratos e serviços.

## 🛠️ Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub
